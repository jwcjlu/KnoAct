# 扫雷图标来源

本目录下的 `smile.png` / `lose.png` / `win.png` / `flag.png` / `mine.png`
取自开源项目 [zyrate/Minesweeper](https://github.com/zyrate/Minesweeper) 的
`out/production/MinesweeperV1/icons/` 目录（Java 扫雷 GUI 项目）。

> **注意**：该仓库**未声明 LICENSE**，按 GitHub 默认即「保留所有权利」。
> 这里的图标仅用于本项目内部使用；若要对外分发（上架应用商店等），
> 请先联系原作者取得授权，或换成自绘图标。

## 用法

| 文件 | 用途 |
| --- | --- |
| `smile.png` | 扫雷进行中状态的表情（同时是「重开」按钮） |
| `lose.png` | 踩到雷后的失败表情 |
| `win.png` | 全部通关后的表情 |
| `flag.png` | 长按插旗 |
| `mine.png` | 雷（失败时揭示，以及踩中的那颗雷） |
