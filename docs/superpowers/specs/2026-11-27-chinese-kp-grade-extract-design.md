# 语文课内知识点按年级抽取（词表仅册末）设计

## 背景

课内拆课曾把识字/写字/词语与「会认的字」「园地」等一并塞进 `WordBank` / `KnowledgePoint`，与册末字词表回填冲突，且知识点过宽、无年级侧重。

## 决策

1. **语文课内只抽知识点 + 课文**；`words` 恒为 `[]`。词条只由 `apply_chinese_word_tables` 册末回填；无册末表则空着，家长可手填。
2. **知识点白名单**（仅本课页真实出现的点）：拼音与汉字 / 词语 / 句子 / 阅读基础 / 积累与运用。
3. **年级三档侧重**（读 `PdfDocument.grade`；缺省按 3–4）：
   - 1–2：拼音、笔画偏旁、简单词义
   - 3–4：近反义、关联词、把/被、修辞、段意、查字典/病句入门
   - 5–6：语境辨析、病句、句式转换、概括体会、描写/说明方法、成语古诗
4. **边界**：整表识字/写字/词语不进 KP（可写「形近辨析」类关系句）；日积月累/口语交际/习作仅当本课页就是该模块时写入。
5. **英语/数学**抽取不变。

## 接口

- `extract_lesson_content(..., grade: int | None = None)`
- `_run_extract` 从 `PdfDocument.grade` 传入
- 语文 AI 失败兜底：`words=[]`，`points=[]`，仍可有 `text` 兜底

## 非目标

- 不改册末表检测/回填逻辑
- 不改家长端基础知识 UI
- 不按年级改每日任务选题算法（仅改提取 prompt）
