# 语文册末识字 / 写字 / 词语表回填

日期：2026-11-25  
状态：已确认（brainstorming）  
前置：`2026-11-25-chinese-word-kinds-design.md`（`WordBank.kind` + 听写过滤）  
原则对齐：原料层识记；册末表是权威词源；知识点抽取不改

## 一句话

> 语文教材册末（或单元末）的**识字表 / 写字表 / 词语表**专门页，在拆课提取末自动解析，并按课序回填到各课对应 `kind`；知识点仍走原课内抽取。

## 背景

`#8` 已把课内 AI 输出拆成 `recognize|write|phrase`，但真源往往是教材**后面的专门汇总页**（按课号 `1` `2` `4`… 分栏列词），不是每课正文页。  
英语已有对称链路：`_detect_word_list` → `apply_word_list` → 按 Unit 序号覆盖各课生词。语文缺这一环。

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 表范围 | **识字表 + 写字表 + 词语表** 三种都回填 |
| 课映射 | 全书语文课按 `start_page` 排序得课序 N；表中课号 N → 第 N 课；缺号跳过；对不上时家长编辑手调 |
| 覆盖语义 | **按 kind 覆盖**：词语表只换 `phrase`，写字表只换 `write`，识字表只换 `recognize`；知识点不动 |
| 触发 | 与英语一致：`_run_extract` 末自动跑（无单独按钮本轮） |
| 无册末表 | 保持课内提取结果 |
| 本轮不做 | 标题「第 N 课」智能匹配、单元内局部编号、单独家长按钮、改知识点抽取 |

---

## 一、检测与拆课页裁剪

### 1.1 页识别

在 `pdf_split` 为语文增加册末表检测（可复用/平行于 `_detect_word_list`，**不得**再写死 `subject != "英语"` 才检测）：

- 标题或页首命中：`识字表` / `写字表` / `词语表`（允许带「会认的字」等副题）。
- 续页：同表无新标题、或以课号分段延续 → 并入同一表区间。
- 一书可有多段（每单元一套）；检测结果为若干 `{kind, start_page, end_page}`。

### 1.2 裁剪末课

仿英语：最后一课正文的 `end_page` 不得吞进册末表页；可选追加只读汇总课（标题如「词语表」），**不进听写池**（沿用/扩展 `is_word_list_title` 类判断，或语文专用 `is_cn_table_title`）。

---

## 二、解析

### 2.1 输入

对每个检测到的表区间取页面文本（OCR 回退与英语 Word list 同级策略）。

### 2.2 分段规则

- 行首课号：`^\s*(\d{1,2})\s*` 或独立成行的课号，开启新桶。
- 桶内：连续汉字词/字（词语表多为双字词；识字/写字多为单字），去空白与标点。
- 同桶同词去重；`extra` 本轮可空（册末表通常无拼音列，或后续再补）。

### 2.3 输出

```text
{ kind: recognize|write|phrase,
  by_lesson_no: { N: [{word, extra}, ...] } }
```

三种表各自一份；合并进 apply 时仍按 kind 分写。

---

## 三、回填 `apply_chinese_word_tables`

### 3.1 课序

```text
lessons = 该文档 subject=语文 的课，排除汇总表课，按 start_page 升序
lesson_no = enumerate(lessons, start=1)  # 与表中 1,2,4 对齐；缺 3 则 by_lesson_no[3] 无课可写，跳过
```

### 3.2 写入

对每个 `(lesson_no, kind)`：

- 若表中无该课号 → 跳过（不清空已有）。
- 若有 → 仅替换该课该 `kind` 的 `WordBank` 行（复用 `_replace_lesson_words` 的 **按 kind 子集** 能力，或新增 `_replace_lesson_words_kind(lesson, kind, items)`）。
- 掌握度：同 `(word, kind)` 尽量挂回原 `word_bank_id`（与 #8 一致）。

### 3.3 与课内提取的时序

```text
_run_extract:
  for each lesson: extract_lesson_content  # 含知识点；词可暂填
  if 语文: apply_chinese_word_tables(...)  # 有表则覆盖对应 kind
  if 英语: apply_word_list(...)            # 现网
```

课内 AI 仍可抽词（兼容无册末表的旧 PDF）；**册末成功则同 kind 以册末为准**。

## 四、入口与 UI

| 面 | 行为 |
| --- | --- |
| `POST .../extract` / `_run_extract` | 语文提取末调用回填；进度文案可含「同步册末字词表」 |
| parent-web | **本轮不新增按钮**；编辑三栏仍可手调错位课号 |
| 听写 | 无新逻辑；继续吃 `WordBank.kind` + `dictation_kinds_语文` |

---

## 五、验收

- 有册末三表的人教样张：各课 `phrase`/`write`/`recognize` 与表中对应课号一致（缺号课该 kind 不被误清空）。
- 知识点条数与回填前后一致（回填不碰 points）。
- 无册末表 PDF：行为与只跑课内提取相同。
- 英语 Word list 回归：现网测试仍绿。
- 听写池不抽「词语表/识字表/写字表」汇总课（若建了汇总课）。

## 六、明确不做

- 用标题「第 N 课」做主映射（本轮仅课序；错了手调）。
- 单元内「局部 1..k」与全书课序混用的自动消歧。
- 单独「从册末回填」按钮。
- 改动知识点 prompt / 解析。
- 宣称册末回填等于「会用这些词」。

## 七、9 问（原料层）

1. 识记型（字词原料）。  
2. 关系：课号 ↔ 课表权威词表。  
3. 无变换；不得宣称理解。  
4. 通过：听写 + SRS（既有）。  
5. 孩子产出在听写；回填是系统备料。  
6. 通道：现听写。  
7. 全年级语文。  
8. 测不准：课序错 → 编辑三栏手调；未决不进掌握度百分比。  
9. 只影响「原料从哪来」，不影响「学会了没」的判据。
