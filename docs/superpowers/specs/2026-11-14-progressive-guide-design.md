# 递进式规律引导 + 识记「认→背→测」设计

日期：2026-11-14  
状态：已确认（brainstorming），待实现  
范围：重构专项训练（drill）的步序体验——解决「一个练习 17 步太长」「观察对比不足、无法总结规律」两个问题。

## 背景与问题

现有 explore（探究型）的步序是「观察→归类→归纳→陷阱」，但有两个体验缺陷：

1. **步序机械铺开**：每个探究条目固定走「归类/归纳/陷阱」3 步，条目一多就展开成 17 步甚至更多，体验太差（小学五年级注意力仅 15-20 分钟，单任务应 5-8 分钟）。
2. **观察不足**：`observe` 步只是组级一张规律卡（`_RuleCard`），一次展示 compare 正反例，孩子扫一眼就过，没有「渐进揭示」的过程，无法真正总结规律。

核心诉求：**像教师一样，把规律一步步揭露出来，让孩子渐进掌握**；同时**学习不要太难，但要保证「理解」和「能用」**。

## 目标

1. 一个练习控制在 **5-8 步**（不再是 17 步）。
2. 探究型内容的「观察」改为**递进引导链**（guide）：多轮「提问→选择→揭示」，最后填空归纳，让孩子自己总结规律。
3. 识记型内容的步序从「认→用→快测」改为 **「认→背→测」**（更贴合古诗/生字/短语等识记内容）。
4. 作答**混合**：引导前期选择题（低门槛），最后归纳填空题（自己总结）。
5. **一练习一规律**（本次只做 guide + 认背测；「布置时按规律拆任务」留后续）。

## 已锁定决策

| 项 | 决定 |
|----|------|
| 探究步序 | 观察引导（guide 链）→ 练习（归类 + 陷阱） |
| 识记步序 | 认 → 背 → 测 |
| guide 结构 | AI 生成多轮 `{prompt, samples, options, answer_index, reveal}`，末轮 `{prompt, answer, reveal}` 填空归纳 |
| 作答形式 | 混合：前面选择题（点选项），最后归纳填空题 |
| 观察原则 | 递进揭示，每步在前一步基础上深入，不一次给结论 |
| 学习原则 | 不难（低门槛、步数少），但保证理解（充分观察）+ 能用（练习验证） |
| 挖空（背） | 规则挖空：每句挖 1-2 个关键位置，非 AI 判断 |
| 一练习一规律 | 本次不做「布置拆任务」，后续再落地 |

## 数据模型

### `TrainingItem.explore` 字段（explore 条目）结构变更

原结构 `{compare, classify, formula, trap}`，改为：

```json
{
  "guide": [
    {
      "prompt": "看这三句话，它们有什么共同点？",
      "samples": ["月亮像一条小船", "云朵仿佛棉花糖", "弟弟像小猴子一样爬上爬下"],
      "options": ["都有「像」字", "都在写月亮", "都很短"],
      "answer_index": 0,
      "reveal": "对！它们都用「像/仿佛」把一个东西比作另一个东西。"
    },
    {
      "prompt": "「月亮」和「小船」是一类东西吗？",
      "options": ["是一类", "不是一类，但形状像", "都是圆的"],
      "answer_index": 1,
      "reveal": "对！本体（月亮）和喻体（小船）不是同类，但有相似点。"
    },
    {
      "prompt": "「他长得像他爸爸」算比喻吗？为什么？",
      "options": ["算，因为有「像」", "不算，是同类比较", "算，都在比"],
      "answer_index": 1,
      "reveal": "对！比喻必须把「不同类」的事物比较，「他」和「爸爸」是同类，所以不算。"
    },
    {
      "prompt": "现在你来总结：比喻 = 本体 + 比喻词（像/仿佛） + ___",
      "answer": "喻体",
      "reveal": "太棒了！你自己总结出了比喻的规律！"
    }
  ],
  "classify": {
    "items": ["弯弯的月亮像一条小船", "小鸟在枝头唱歌", "湖水很清很清", "春风像妈妈的手一样轻", "花儿对着我们微笑"],
    "boxes": ["比喻", "拟人", "直接描写"],
    "answers": {"弯弯的月亮像一条小船": "比喻", "春风像妈妈的手一样轻": "比喻"}
  },
  "trap": {
    "question": "只要句子里有「像」字，就一定是比喻句吗？",
    "answer": "不一定",
    "explain": "「像」有时表示猜测、举例或同类比较，比喻必须把两个不同类的事物比较并找到相似点。"
  }
}
```

- `compare` 和 `formula` 字段**移除**，合并进 `guide`（compare 变成 guide 前几轮的 samples，formula 变成 guide 最后一轮的填空归纳）。
- `classify` 和 `trap` **保留**，作为「练习」环节。

### guide 生成原则（AI prompt 要求）

1. **递进**：每轮在前一轮基础上深入（先发现共同点 → 理解关键区别 → 反例冲突 → 自己归纳）。
2. **不一次给结论**：每轮只揭示一点，最后才让孩子自己归纳完整规律。
3. **选择 + 填空混合**：前 N-1 轮选择题（2-4 个选项），最后一轮填空题（孩子写规律）。
4. **反例冲突**：至少一轮用反例制造认知冲突（如「他像他爸爸」不是比喻）。
5. **教师口吻**：reveal 用鼓励、启发式的语言，不说教。

## 步序

### 识记型（memorize）条目：认 → 背 → 测

| 步 | 交互 | 说明 |
|----|------|------|
| 认 | 规律卡（组级，一次） | 展示释义 + 规律引导，先看懂再背 |
| 背 | 挖空补全 | 每句挖 1-2 个关键位置，孩子补全（有上下文提示） |
| 测 | 填空/找茬 | 无提示检验是否真记住 |

挖空规则：对 `primary`（如「床前明月光，疑是地上霜」），**按句切分，每句挖 1 个字**（优先挖每句的实义词，如名词/动词，不挖虚词和标点），前端渲染成「床前明___光，疑是地___霜」。规则：把 `primary` 按标点/空格切成若干片段，每片段挖掉中间的 1 个实义字（有词库则挖关键词，无则挖片段中间偏后的字）。判分用 `normalize_answer` 比较补全后的完整串。

### 探究型（explore）条目：观察引导 → 练习

| 步 | 交互 | 说明 |
|----|------|------|
| 观察引导 | guide 链（3-4 轮渐进问答） | 逐轮「提问→点选项→揭示」，最后填空归纳 |
| 练习·归类 | 拖拽归类（classify） | 把场景拖到正确概念箱 |
| 练习·陷阱 | 陷阱题（trap） | 反直觉题打破错误直觉 |

> **步数控制**：一个探究练习 = guide 链 3-4 轮 + 归类 1 题 + 陷阱 1 题 ≈ 5-6 步，符合「5-8 步」目标。一个识记练习 = 认 1 + 背（每条目 1）+ 测（每条目 1），条目 2-3 个时约 5-7 步。

## 前端渲染

### guide 链渲染（探究的「观察引导」）

一个 guide 链是多轮问答，每轮：

1. 显示 `prompt`（教师提问）+ `samples`（正例材料）
2. 孩子点 `options` 里的一个
3. 答对 → 显示 `reveal`（教师揭示）+ 「下一步」
4. 答错 → 提示「再想想」，可重试
5. 最后一轮（填空）→ 孩子输入答案，判分（`normalize_answer` 或 LLM 兜底）

### 识记「背」渲染

`primary` 挖空显示，孩子填挖空的部分，判分 `normalize_answer`。
