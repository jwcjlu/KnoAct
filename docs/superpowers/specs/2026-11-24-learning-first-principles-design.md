# KnoAct 学习第一性原理 设计

日期：2026-11-24
状态：已确认（brainstorming）
范围：为 KnoAct 确立「学习」的第一性原理，作为后续功能设计的裁判标准；写入 `AGENTS.md`，不改功能代码。

## 背景与目标

KnoAct 的功能横跨「可测的学科掌握」与「不可直接测的学习状态」两类，
但仓库里没有任何一处说清楚**「什么算学会了」**。结果是：

- 每个功能各自定义「学会了没」，无法互相裁决（刷题、背诵、对话、游戏各说各话）。
- 新功能没有开工门禁，「加个练习环节」就能进主干，事后才发现测不出东西。
- 动机类设计（积分、游戏）与掌握类数据混用，容易出现「分高＝学得好」的错误推断。

目标：立一条**有裁决力**的学习第一性原理，明确：

1. 什么算「学会」（主原理）。
2. 什么算「学得下去」（从属原理）。
3. 不同类型内容的裁定标准（分层裁判，不搞一刀切）。
4. 新功能开工前必须回答的问题（门禁）。

## 一、主原理：什么算「学会」了

> **学习 = 把教材里的规律挂成结构 → 在直觉被打破处把它提取出来 → 在无提示条件下独立产出。**

三层各有唯一职责，缺任何一层，都只是「感觉学过」：

| 层 | 管什么 | 判据 |
| --- | --- | --- |
| **结构** | 提取的**对象** | 是这类东西的共同点 / 规律，不是孤立事实 |
| **冲突** | 提取的**时机** | 发生在「我以为…结果不是」之后，而非顺畅复述之后 |
| **提取** | **通过**的标准 | 无提示、无材料下的独立产出 |

### 裁决规则

1. 看得懂、听得懂、被讲明白 → **不算学习事件**，只是准备。
2. 提示下的答对 → 不算通过，只算「引导中」。
3. 只记住孤立事实 → 不算掌握，哪怕全对。
4. 一路顺畅答对、从未被打破直觉 → 存疑，需变式验证。

> 第 1 条的直接后果：辅导式对话（如 `/api/ask`）本身不构成学习事件，
> 它产生的是「理解」；理解是否成立，由下面的证据阶梯判定，不由对话内容自证。

## 二、理解的证据阶梯

「理解」不是学习的前置条件，也不是通过标准，而是**提取能力的一个中间档位**。
判它只能看孩子能否自己产出，不能看对话里说了什么。

| 级 | 证据形态 | 判定方式 | 仓库现状 |
| --- | --- | --- | --- |
| **L0 复述** | 重复原文 / 复述 AI 的话 | **不算理解** | 目前对话留下的唯一痕迹 |
| **L1 重述** | 无原文提示，用自己的话说出核心 | 与原文做语义等价判定（非同义即不通过） | **缺** |
| **L2 举例** | 能举新例 / 能区分正反例 | 归类题、判断正误 | 有：`explore.classify` |
| **L3 迁移** | 在新情境、变式、陷阱中正确应用 | 陷阱题、练习册变式 | 有：`trap` / practice |

### 辅导式对话（`/api/ask`）的定位

它是**能产生理解**的功能，但产出必须被测出来才算数：

1. 对话结束**可以**（非必须）收一个「你说说看」——一句话复述，
   **AI 只判语义是否等价，不许再补充讲解**（否则又退回 L0）。
2. 这条复述落成 L1 证据。
3. 跳过复述 = 本次只记为 L0，不计入理解证据；后续进入错题 / 复习任务时，
   按 L2 / L3 正常裁定。
4. 成功指标不是对话轮次，而是：**对话后同一知识点的 L2 / L3 首次正确率，
   是否高于未对话的对照**。

> 第 1 条与第 3 条是待整改项，本次不实现。列入「待整改」清单，不阻塞本原理生效。

## 三、从属原理：什么算「学得下去」

顺序即优先级，不可打乱：

| 优先级 | 条件 | 含义 | 可观测指标 |
| --- | --- | --- | --- |
| 1 | **低门槛开始** | 单次任务落在一次注意力之内（沿用 5–8 分钟） | 开始率、放弃点位置 |
| 2 | **难度适配** | 难度略高于当前能力，由**数据**决定而非年级 | 连对 / 连错分布、难度切换频率 |
| 3 | **错误安全** | 错误不产生惩罚性反馈；家长端不得把掌握度变成考核指标 | 连错后重试率、家长催办与代做痕迹 |

从属原理只裁定「愿不愿意学、学不学得下去」，**不裁定「学会了没」**。

## 四、分层裁判：三类内容，三套标准

| 类型 | 适用内容 | 三层怎么落 | 通过判据 |
| --- | --- | --- | --- |
| **探究型** | 数学规律、句型、修辞、周长面积 | 三层全开：结构 → 冲突 → 提取 | 引导链归纳 + 归类 + 陷阱全过 |
| **识记型** | 生字、单词、古诗、短语 | 结构层退化为「形—义—用」关联；**不要求**认知冲突 | 无提示产出（认 → 背 → 测） |
| **习惯 / 情感型** | 按时开始、不畏难、敢提问 | 不受主原理裁定 | 只受从属原理裁定 |

### 禁止条款

**不得用 A 类型标准去要求 B 类型内容。** 两类常见产品病都由此挡住：

- 用「要有认知冲突」去逼古诗背诵 → 孩子背不出来还挫败。
- 用「能提取就算会」去放过数学规律 → 会做套路题但不懂原理。

## 五、现有功能裁定表

| 功能 | 裁定 | 理由 |
| --- | --- | --- |
| 递进引导链 `guide` | 达标 | 三层齐全，是原理的样板实现 |
| 识记「认→背→测」 | 达标 | 符合识记型标准 |
| 陷阱题 `trap` | 达标 | 冲突层的唯一真实实现 |
| 归类 `classify` | 部分 | 有 L2，但缺结构层归纳 |
| 阅读理解题 | 部分 | 只到提取层，无冲突、无结构 |
| 听写 | 达标 | 典型识记型：无提示产出 |
| 边读边问 `/api/ask` | 部分 | 可产生 L1–L3，但目前无证据留存 |
| 思维训练小游戏 | 不受裁定 | 习惯 / 情感型（动机），**不产生学科掌握** |
| 积分 | 不受裁定 | 动机工具，**不得用于判定掌握度** |

## 六、裁决程序：新功能开工前必答的 5 个问题

任何涉及学习内容的功能（新增或改动），先回答，答不出就不进入实现：

| # | 问题 | 不通过的表现 |
| --- | --- | --- |
| 1 | 它属于哪一类（探究 / 识记 / 习惯）？ | 「都涉及」＝没定类，一律退回 |
| 2 | 它训练的是哪个**规律 / 结构**？能用一句话说出吗？ | 只能说出「练习阅读能力」＝无结构 |
| 3 | 通过的证据是什么，**在无提示条件下**怎么取到？ | 「AI 说理解了」＝L0 冒充 |
| 4 | 认知冲突点在哪里（识记型可写「不适用」）？ | 探究型答不出＝退回 |
| 5 | 它影响「愿意学」还是「学会了没」？两者**不得混** | 「答对有积分，所以掌握了」＝混层 |

### 两条硬约束

1. **成功指标必须落在已有数据表上**（`WordMastery` / `KnowledgeMastery` /
   `AnswerRecord` / `BrainGameResult` 等）。落不上去，说明它测不出东西，先别做。
2. **不得用 A 类型标准要求 B 类型内容**，也不得用积分 / 时长代表掌握度。
