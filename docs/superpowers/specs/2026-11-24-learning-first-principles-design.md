# 第一部分：原理本体（承 v2，一处修正）

## 1.1 学习的本质是思考

> **学习 = 在关系上做一次信息增量（压缩 / 反事实 / 生成），且这次增量由孩子本人完成。**

思考不可直接观测，唯一可用的判据：

> **孩子的这个答案，能不能靠「照搬输入」复现？能 → 不是思考。**

| | 检索（非思考） | 思考 |
| --- | --- | --- |
| 输出与输入的关系 | 输出 ⊆ 输入（搬运） | 输出 ⊄ 输入（变换） |
| 信息量 | 不变 | 必须增加 |
| 例 | 默写「比喻 = 本体 + 比喻词 + 喻体」 | 判断「他长得像他爸爸」为什么不算比喻 |

**结构 / 冲突 / 提取三层只是痕迹，不是本体。** 孩子把背下来的结论默写出来（过结构层）、
被陷阱题打中一次（过冲突层）、再把答案写出来（过提取层），三层全过而零思考——因为三层都是产物。

## 1.2 三种可观测变换

| 变换 | 含义 | 仓库对应 |
| --- | --- | --- |
| **压缩** | 多个例子 → 一条更短的规则 | `guide` 末轮填空归纳 |
| **反事实** | 改变一个条件会怎样 | `trap` |
| **生成** | 用规则造出教材里没有的东西 | **缺**（造句/举新例/自编题） |

> v3 补充：「教 AI」是最自然的**生成**形式（见 5.4），可补上此缺口。

## 1.3 反检索否决条款

思考层的通过证据，若能被「检索原话」解释，一律不算通过：

| 维度 | 检测方式 |
| --- | --- |
| 用词 | 逐字复现教材/AI 原话 → 不算；语义等价但表述不同 → 算 |
| 换问法 | **必测**：同一知识点至少两种问法都答对 |
| 解释 | 能答「为什么」「什么情况下不成立」才算 |
| 变式 | 换数字 / 换情境重做 |

**同一变换至少测两次，第二次换表象。** 抄的、猜的都可能有一次增量表象。
注意：「努力感」不是思考（回忆一个词很费劲但信息量不增，那是检索）。

## 1.4 产出不等于「说」

**这是 v2 最严重的错误。** v2 写「只能看孩子能否自己产出」，但把产出窄化成了语言。
小学低年级孩子的瓶颈常在**表达**，不在理解：

| 真实状态 | 表现 | v2 判成 |
| --- | --- | --- |
| 想通了，但说不出来 | 憋着、说半句、用词不准 | **没想通** ❌ 冤枉 |
| 想通了，用动作/图示表达 | 摆对小棒、指对位置 | **没想通** ❌ 冤枉 |
| 没想通，但背得流利 | 顺畅复述规则 | 部分被反检索挡住 |

> **产出是多通道的，语言只是其中一个通道。**

| 通道 | 形式 | 判定方式 |
| --- | --- | --- |
| 语言 | 说、写 | 语义等价 |
| 图形 | 画、连线、标位置 | 结构同构 |
| 动作 | 拖拽、摆放、排序 | 顺序/分组正确 |
| 选择 | 从若干表述里挑对的 | 唯一正确 |

**这不是降低标准，是承认理解有多个出口。** 而且多通道更严——所有通道必须指向同一结构。

# 第 1.5 节：核心原则——允许未决（v4 新增）

> **判据侧测不准时不强行判决（记为未决）；内容侧学不会时不强行通过（记为悬置）。
> 这是同一条原则的两个场合——承认第三种状态。**

二元判决在信息不足时**必然出错**，而唯一的修法不是选哪一边，是**不判决**。

| | 判据要准不要严 | 允许不会 |
| --- | --- | --- |
| 系统现在的假设 | 每个答案必须判对或判错 | 每个知识点必须学会或未学会 |
| 造成的伤害 | 测不准时强行二选一，冤枉 | 学不会时强行二选一，反复练 |
| 解法 | 承认「**这一测结果不确定**」 | 承认「**当前尚未学会**」 |

v4 把这两条合并成一条原则，因为它们做法完全一致。分开写会让文档更长，也更难执行。

## 1.5.1 「准」是可分解的三个能力，不是一个阈值

| 能力 | 含义 | 怎么测 |
| --- | --- | --- |
| **信度** | 同一状态重复测，结论一致 | 隔期重测同一知识点 |
| **收敛效度** | 不同通道测，结论一致 | 说对 + 指对 + 做对 |
| **区分效度** | 能分开「想通」与「背下」 | 换问法 + 反检索 |

**关键**：如果判据缺第三种能力（区分效度），放宽阈值不会让它变准，只会让它**换一种方式不准**。

这解释了为什么「多给点分」是错的解法——它动的是阈值，而问题在能力。

## 1.5.2 假阴性与假阳性的危害不对称，但按内容层级区分

v3 写「假阴性危害更大」，这句话过于绝对，需修正。不对称性**取决于内容层级**：

| 层级 | 假阳性（放过）成本 | 假阴性（冤枉）成本 | 该往哪边偏 |
| --- | --- | --- | --- |
| **原料层**（生字/单词） | **低**——多练几次自然暴露 | **高**——重复学已会的很烦 | **宁松** |
| **思考层**（规律/原理） | **高**——错误规则被自动化，会锁住 | 中——浪费时间，可恢复 | **宁紧，但先换通道** |
| **发展性未到** | 不适用 | 不适用 | **该悬置，两边都不判** |

思考层之所以「宁紧」，正是「只自动化想通的」那条硬规则的后果：**放过一个没想通的孩子，
等于让他把错误规则练成自动化**，之后修正要先拆旧通道。这个成本高于多教一遍。

而原料层完全相反：生字放过一次毫无损失，SRS 迟早会再遇到。

> 准确表述是：**先判断是哪一层、错判的后果是什么，再决定松紧。** 不是全局放宽。

## 1.5.3 准度预算按「判决后果」分配

准是要花钱的（多问一遍、多换一个通道）。不能每道题都测三遍：

| 场合 | 需要多准 | 为什么 |
| --- | --- | --- |
| **首次判定某知识点未掌握** | **高** | 决定后续全部路径，错了会连锁 |
| **判断能否推进进度** | **高** | 错了会带着缺口往前跑 |
| 日常复习 | 低 | 多测一次机会，粗判也没事 |
| 原料层练习 | 低 | 同上 |
| **发展性未到** | **极高但做不到** | 只能悬置 |

落到具体端点：

| 端点 / 场合 | 判决后果 | 预算 | 做法 |
| --- | --- | --- | --- |
| `learning.py` 作业判分（决定推进进度） | **大** | **高** | 双通道 + 两次呈现 + 一次变式 |
| `goals.py` 目标考核 | **大**（家长在看结论） | **高** | 同上，不确定时显示「待复核」而非百分数 |
| `tasks.py` 每日任务 | 中 | 中 | 单次 |
| 听写 | **小**（SRS 迟早再遇到） | **低** | 单次，立即反馈 |
| 复习 / 练习册 | 小 / 中 | 低 / 中 | 单次（练习册 + 错因） |

## 1.5.4 测不准时的正确动作

当证据不足时（只答了一次、通道单一、用时极端），三个选项里：

| 选项 | 结果 |
| --- | --- |
| 判通过 | 可能漏放 |
| 判不通过 | 可能冤枉 |
| **记录为「未决」，下次带更强证据再判** | **两个错都不犯** |

「未决」不是偷懒，是**在信息不足时唯一不犯错的选择**。

## 1.5.5 未决的生命周期

| 阶段 | 规则 |
| --- | --- |
| **产生** | 证据不足（只答一次、通道单一、用时极端）；或 ≥2 次不同表征后仍失败 |
| **粒度** | **一条可陈述的规律或一个知识点**，不是单个字词（原料层只需间隔，不需悬置） |
| **发起方** | 孩子自己 → 需系统复核后生效，防滥用；系统判定 → **必须告知并给孩子否决权**；家长 → **只能建议，不能强制** |
| **上限** | 同时悬置 ≤ **3 个知识点**，且不超过当前课知识点的 **30%**；最短停留 ≥ **3 天** |
| **回归** | **混在正常内容里，不标注、不提「复习」**——明确提示会唤起自我威胁 |
| **到期动作** | **改内容**（换表征/拆小/补前置/降难度），不是再测孩子一次 |
| **归属** | 必须归属到**内容问题 / 教学问题 / 时间问题**之一，否则算系统失职 |

### 粒度决定机制是否可用

| 粒度 | 风险 |
| --- | --- |
| 单个生词 | 池太碎，悬置无意义 |
| **单个知识点 / 单条规律** | **合适**——有明确的「会不会」 |
| 整课 | 太粗，一次卡住丢掉整课 |
| 整专题 | 等于放弃 |

**实现含义**：`WordMastery` 不用改，只需给 `KnowledgeMastery` 加状态。

### 发起方的可靠性不同

| 发起方 | 可靠性 | 处理规则 | 为什么 |
| --- | --- | --- | --- |
| **孩子自己**（「这个我还想再想想」） | 可能被滥用逃避 | 需系统复核后生效；连续滥用则暂停该权限 | 元认知训练价值高，但要防退化 |
| **系统判定** | 可能误判 | **必须告知并给一次否决权** | 防冤枉，也防悄悄降低标准 |
| **家长** | 会变成压力 | **只能建议，不能强制** | 家长强制等于把焦虑转嫁 |

第二行的「否决权」很要紧：系统说「这个你可能还不会，先放着？」孩子说「不，我会」，
那就该测一次，而不是直接悬置。**这是防止系统替孩子下结论。**

### 期限约束的具体值

| 约束 | 建议值 | 依据 |
| --- | --- | --- |
| 同时在悬置的知识点数 | **≤ 3** | 超过 3 个说明不是个别内容问题 |
| 悬置占当前课知识点比例 | **≤ 30%** | 超过说明内容或讲解有问题 |
| 悬置的最短停留 | **≥ 3 天** | 防止当天反复横跳（卡住→悬置→明天又出现→又悬置） |

### 「发展性未到」不是诊断，是事后归类

**v3 把它列为五种「不会」之一，读起来像能当下判断的类型。但实际做不到：**

> **你无法在当下区分「这次没懂」和「认知还没到」。** 两者当天表现完全一样——教了几遍仍失败。

唯一区分方式是**换个时间再试**：

| 时间点 | 表现 | 事后归类 |
| --- | --- | --- |
| 当下 | 教 3 种表征仍失败 | 「未决」 |
| 3–7 天后 | 换表征后通了 | **学了没懂**（表征问题） |
| 1–3 个月后 | 同样内容自然通了 | **发展性未到**（时间问题） |
| 一直不通 | 仍失败 | 需要重新诊断（可能缺前置） |

所以正确的机制不是「识别发展性未到然后长间隔」，而是：

> **所有卡住的内容都先进「未决」，用短间隔试一次；短间隔不行，自动延长到长间隔。**

这不需要任何前瞻判断——只需要**两个档位的重试间隔**，靠结果反推归类。
实现难度大幅下降：不需要诊断模型，只需要「失败次数 → 间隔」的映射。

额外好处：**归类结果事后可修正**。若 3 个月后通了，系统才知道「当时是没到」，
这个信息可回填到难度校准——下次遇同类内容，一开始就给更长间隔。

### 回归时不能声张

| 方式 | 后果 |
| --- | --- |
| 明确提示「你之前不会的，现在再试试」 | **唤起自我威胁**，孩子会抗拒 |
| **和普通内容混在一起出现，不做任何标注** | 无压力，正常作答 |

**规则：回归时不告知、不标注、不计入「复习」字样。** 它在孩子眼里就是一道普通题。
这和「交错练习」是同一思路：**改变排列，不改变提示语。**

### 措辞决定使用率

| 按钮文案 | 孩子的心理 | 使用率 |
| --- | --- | --- |
| 「我不会」 | 承认失败，丢脸 | **极低** |
| 「先放一放」 | 暂时搁置，不丢脸 | 中等 |
| **「这个我还想再想想」** | **主动选择，甚至是积极的** | **最高** |

同一件事，措辞把它从「承认不会」变成「主动安排」。这不只是文案技巧——
**它决定了孩子能不能如实暴露状态**。

## 1.5.6 未决会累积成债

若 30% 的内容挂着未决，系统**没法规划**——不知道该讲什么、该复习什么。

**到期强制裁决的正确做法不是判孩子：**

| 做法 | 后果 |
| --- | --- |
| 到期强行判「会」 | 回到假阳性 |
| 到期强行判「不会」 | 回到假阴性 |
| **到期改内容** | **正确**——换表征、拆小、补前置、降难度 |

理由很直接：**大量未决的原因通常在内容侧，不在孩子侧。** 一个知识点反复未决，
多半是拆课把它切碎了、AI 讲解绕了、或者缺前置。

这同时接上 `_gen_dictation` 的「永不移出」——**两者是同一个病：系统只改孩子，不改内容。**

## 1.5.7 每个未决必须有归属

如果系统可以永远说「未决」，它就退化成什么都不教——**「我们不知道」成了坏内容的庇护所。**

> **每个未决必须在期限内被归属到三类之一，否则算系统失职。**

| 归属 | 判断依据 | 处理 |
| --- | --- | --- |
| **内容问题** | 多个孩子都在同一点悬置 | 改拆课 / 改讲法 |
| **教学问题** | 单孩子在一点悬置，换表征后通了 | 换表征 |
| **时间问题** | 1–3 个月后自然通了 | 回填难度校准 |

第二、三类的区分靠**重试结果**反推，不需要前瞻判断。
第一类的判据是**跨孩子聚合**——一个点若只有个别孩子悬置，是个体差异；大面积悬置，是内容问题。
**这个数据现在完全没有被使用。**

## 1.5.8 必须防的退化：从「判不准」变成「不敢判」

「允许未决」听起来稳妥，但有退化路径：**系统对所有难判的情况都说未决，永远不给出结论，
也永远不推进。** 表现隐蔽——不是崩溃，是**进度停滞**。孩子每天做题，但一直在原地。

| 防线 | 内容 |
| --- | --- |
| **未决必须到期** | 不能无限挂着 |
| **到期默认动作是改内容，不是再判一次** | 否则变成「反复测同一个东西」的循环 |

第二条是关键：**若到期只是再测一次，大概率还是未决，因为什么都没变。**

## 1.5.9 百分比这个抽象本身是错的

`parent-web` 现在给家长「已掌握 12 · 薄弱 8 · 共 20」和「掌握度 62%」。问题不在「未决放哪」，
而在**一个数不能同时表示值和方差**：

| 维度 | 回答什么 | 现状 |
| --- | --- | --- |
| **覆盖度** | 这个范围学了多少 | 被当成百分比 |
| **深度** | 能承受多远的情境变化（见 5.5） | **完全没有位置** |
| **确定度** | 我们对这个判断有多确信 | **完全没有位置** |

且目标页的进度是**硬编码**的：

```js
const statusMap = {pending:[...0,'尚未开始'], in_progress:[...50,'进行中'], done:[...100,'已达成']};
```

`mastery` 这个 float 实际算的是「最近几次对得多不多」——**是近期正确率，被当成进度条画出来**。

### 家长要的不是度量，是决策

`掌握度 62%` 不能指导任何动作——家长看完，唯一能做的还是「多练练」。
这份报告真正该回答的是：**下周该做什么。**

| 度量型报告（现在） | 决策型报告（应该） |
| --- | --- |
| 掌握度 62% | 本周要做这 3 件事 |
| 已掌握 12 · 薄弱 8 | 「像」这条规则还在用旧理解，已安排 2 道反例 |
| 目标进度 50% | 暂时放下 2 项：「1/2 比 1/3 大」等 3 周再试 |
| 当天做题明细 | 昨天他自己开始了，中间卡了 2 次没有求助 |

**未决不进任何百分比，而是进「暂时放下」清单，带原因和回归时间**——家长看到的是「有安排」，
不是「不知道」。这把「未决放哪」的问题直接消解了：**它不进分母，它是一个待办事项。**

### 悬置率是内容质量的指标

> **如果一个内容被大量孩子悬置，那不是孩子的问题，是内容的问题。**

| 现象 | 可能的真实原因 |
| --- | --- |
| 某个知识点全班悬置 | **拆课/讲解有问题**，或超纲 |
| 只有个别孩子悬置 | 个体差异，正常 |
| 悬置集中在某类题型 | 题型设计不合理 |
| 悬置率突然上升 | 难度整体跳了，或前置没教 |

这给系统补上了一个缺失的反馈回路：**反向检验拆课与 AI 出题质量**。
这个指标该给**运营/教研**看，**不该给家长看**（家长看了只会催孩子）。

# 第二部分：两层结构（v3 关键修订：静态分类 → 动态阶段）

## 2.1 两层不是内容的两个类别，是同一件事的两个阶段

| 层 | 内容 | 本质 | 目标 | 达标判据 |
| --- | --- | --- | --- | --- |
| **原料层** | 生字、单词、古诗、短语 | **检索自动化** | 秒取 | 无提示、隔日/隔期仍能取（SRS） |
| **思考层** | 规律、句型、原理、修辞 | **信息增量的变换** | 能推 | 压缩/反事实/生成任一 + 过反检索 |

但两者的关系是**动态的**：

```
未想通 → 想通（思考） → 反复用（自动化） → 秒取（原料）
```

**今天的思考是明天的检索。** 生字的「秒取」最初靠字形分析（思考）；一条数学规律想通几次后
会变成一秒取出的直觉。所以两层不是分类，是**阶段**。

## 2.2 硬规则：只自动化想通的东西

这是从动态视角推出的、v2 完全没有的规则。

> **死记硬背 = 把「没想通」的东西提前自动化。**

危害不只是「没用」，是**会锁住**：一个流畅的检索通道一旦建立，想修正就要先拆掉旧通道，
而孩子已经对它有信心了。这比「没学过」更难办——「没学过」至少是空的。

**判断顺序必须是「想通 → 再用到自动」，不能颠倒。**

推论：**识记型的对象是那些无需推理的约定**（字形、拼写、诗），
**不是「所有暂时想不通的东西」**。想不通的数学规则不能当识记内容塞进去，那等于合法的死记硬背。

## 2.3 检索降低提取成本，思考增加信息量

**没有可检索的原料，就没有可压缩的句子；但只有原料，永远不会有句子。**

原料层达标**不得宣称理解**：听写全对只说明「记住了这个词」，不说明「会用这个词」。

# 第三部分：思考的对象、时机与阻力

## 3.1 对象是关系，不是元素

孩子想不出，几乎从不是因为缺元素：「他长得像他爸爸」里「像」「爸爸」「同类」他都知道，
缺的是「『像』同时承载比喻与同类比较两种关系」。

**禁止条款：不得用「加同类题」应对关系缺口。** 关系缺口上加量只带来更多同类失败，
孩子会据此认定「我就是不会」。要换视角重排关系（`guide` 每轮换一个视角：共同点 → 区别 → 反例）。

## 3.2 【v3 新增】起点是失衡

思考只在**预期遇到冲突**时启动。没有预期就没有可打破的东西，反例只会成为另一条要记住的信息。

**设计规则：先让孩子预测，再给反例。** 预测这个动作把隐性预期显式化，反例才可能造成冲突。

`trap` 现在缺「预测」这一步，直接给题——它的冲突强度取决于孩子恰好有没有那条错误直觉，
带有运气成分。

## 3.3 【v3 新增】错误规则是功能性的，有适用范围

孩子的错误规则**几乎总是有用的**——在他遇到的范围内一直有效：

| 错误规则 | 在哪个范围内有效 | 在哪里失效 |
| --- | --- | --- |
| 乘法让数变大 | 正整数 | × 0.5、× 0 |
| 除以大的数结果小 | 正数 | ÷ 0.5 |
| 「像」就是比喻 | 大多数含「像」的句子 | 「他长得像他爸爸」 |
| 周长大的面积大 | 形状相近时 | 细长 vs 方正 |

**错误不是空白，是一个有适用范围的真规则。**

这解释了**为什么讲了没用**：讲解是**叠加**——「乘法不一定让数变大」加在「乘法让数变大」旁边，
两条规则同时存在，做题时仍用那条更熟悉、更快、更自动的。

> **纠正 = 让旧规则在边界上失效，不是叠加新规则。反例必须打在旧规则的适用边界上。**

| 反例 | 效果 |
| --- | --- |
| 「2 × 3 = 6，乘法让数变大了吗？」 | 无效，旧规则又对了 |
| 「0.5 × 4 = 2，比 4 小。为什么？」 | 有效，落在边界上 |

**能说出「这条规则什么时候不成立」，才是真的修正了它。** 这句话可替代「理解」的一个判定档位，
且天然多通道（可说、可指、可举例）。

## 3.4 「卡住」是思考的唯一外部征兆

| 卡住之后 | 含义 | 数据痕迹 |
| --- | --- | --- |
| 乱试 | 有路径，在搜索 | 试错多但间隔短 |
| 停住不动 | 无路径，也没意识到 | 长时间无操作 |
| 退出 | 判定自己不行 | 放弃点 |
| 提问 | **知道缺什么，会求助** | 提问的具体程度 |

能说出「我卡在哪」本身就是思考的证据（比答对一题更能说明问题）。故从属原理的「别让孩子挫败」
与「必须让他卡」不靠折中，靠**区分卡的类别**：

- **有救的卡**：卡在关系上，且能说出卡在哪 → 让他多卡一会儿，只给最小提示（一句反问，不给答案）。
- **没救的卡**：缺前置原料（生字不认识、题意没读懂）→ 立刻补支撑，别让他耗。

一路顺畅、从未卡过 = 不是在学，是在表演已会。

## 3.5 主体性条款（软约束）

AI 能完成全部三种变换且做得更好。一旦 AI 先做（提问 → AI 归纳 → 孩子点头），
信息增量发生在 AI 那边，**只构成演示，不构成学习**。

变换应优先由孩子产出；AI 首先是**引发者与裁判**（反问、给反例、判语义等价），而非讲解者。
允许必要时先讲，但**讲完必须收一次孩子自己的产出**，否则该次交互只记 L0。

理由不只是理念：**完整答案会消灭提问的价值，也会短路「发现关系」的通路。**

# 第四部分：年龄维度（v3 全新）

## 4.1 同样的内容，可达上限不同

v2 只按内容类型分层，缺了**年龄**。最典型的是**反事实**：v2 把它列为思考的三种变换之一，
并要求探究型必须有冲突。但反事实推理**有发展顺序**——低龄孩子在需要同时抑制现实、
维持假设世界的情境里会系统性失败，而这不是不懂，是**能力还没到**。

> 一年级孩子答不出陷阱题 → 系统判「没想通」→ 但其实他连「假装条件变了」都还做不到。
> **陷阱题在低年级测的可能是抑制控制，不是理解。**

## 4.2 冲突形式按年龄分档

| 年龄 | 冲突形式 | 为什么 |
| --- | --- | --- |
| 低年级（1–2） | **先猜，再看结果** | 只需「我的预期 vs 实际」，不需维持假设世界 |
| 中年级（3–4） | **反例打破规则** | 需抑制旧规则、维持新假设 |
| 高年级（5–6） | **自己构造反例** | 需主动搜索边界 |

三者是**同一条发展线**上的不同台阶，都在制造「预期失衡」，认知负荷不同。
`trap` 是**中高年级的冲突形式**，不该用在低年级；低年级需要的是**预测机制**。

## 4.3 工作记忆预算

低年级工作记忆容量约 4 个组块。若一道题要求**同时握住 6 个元素才能看见 1 条关系**，
它不可完成，与聪明无关。

**两条推论：**

1. **外化元素**，让工作记忆空出来装关系。拖拽、摆小棒、画图，本质都是替孩子保管元素。
2. **换表征**，因为有些关系只在特定表征下可见。竖式之重要不在「规范」，
   而在它把**进位**画成了位置；数轴让「负数比正数小」从一句话变成一个方向。

**产品原则：「想不出来」时先换表征，不是重复讲解。** 重复讲解是在元素维度上加量，缺口在表征维度。

这也解释了纯文字题对小学生特别难：文字要求孩子自己在脑中构建表征，工作记忆全被维持表征占满。

# 第五部分：可用的判据（v3 新增，全部落在已有数据上）

> 本部分的原则：**数据已在库里，只是没人读。**

## 5.1 答 + 指（最高性价比）

> **答完之后，让孩子指出「从哪里看出来的」。**

`quiz.py` 已有 evidence 机制（`evidence` 必须逐字复制原文，服务端校验），
但只对准了 AI，没对准孩子。

产出 2×2：

| 答案 | 出处 | 结论 | 解决了什么 |
| --- | --- | --- | --- |
| ✅ | ✅ | 真会 | — |
| ✅ | ❌ | **蒙对了** | 判分防不住蒙 |
| ❌ | ✅ | **想对了，说错了** | **假阴性**（语言弱但理解对） |
| ❌ | ❌ | 没懂 | 需要重建 |

中间两行以前完全看不见。「❌ + ✅」特别有价值：理解到位但表达没到位，
正确响应是**帮他表述**，不是重讲内容。

**适用边界**：只对思考层内容强制，原料层（听写、默写）不需要——日常负担不变。

## 5.2 反向证据题（防关键词匹配）

| 方向 | 题 | 考什么 | 可作弊性 |
| --- | --- | --- | --- |
| 正向 | 问题 → 答案 + 出处 | 定位 | 关键词匹配可部分作弊 |
| **反向** | **给一句原文 → 这能回答什么问题 / 它在全文起什么作用** | **结构** | **无法关键词匹配** |

反向题要求理解**这句在整体里的功能**，天然是「压缩」变换。
低年级需简化（问「这句在讲谁」而非「起什么作用」）。

## 5.3 错误诊断（数据已在库）

`AnswerRecord` 已存 `question` / `student_answer`（孩子原话）/ `correct_answer` / `duration_ms`。
**错误的原貌完整保留着**，但整条链路在写入时缩成 `is_correct: bool`：

- `mastery.grade_answer` 返回 `bool`，孩子写了什么、错在哪，不再被看。
- `Mistake` 只存**最后一次** `your_answer`，每次再错就覆盖——
  「同一个错答案反复出现」（最有诊断价值的信号）**存不下来**。
- `weakness_report` 只统计 `source_type` 计数（听写错 5 个、阅读错 3 个）——**这是计数，不是诊断**。

错误形态分类：

| 错误形态 | 背后状态 | 该怎么响应 |
| --- | --- | --- |
| 空白 | 无路径（没救的卡） | 补原料，别耗 |
| 过程对、结果错 | 表征对了，执行滑了 | 不是理解问题，别重讲 |
| **同一个错答案反复出现** | **有稳定的错误结构** | 针对这条错规则造反例 |
| 每次错法都不同 | 无稳定表征，在猜 | 退回上一个能站住的台阶 |
| 答案对但用时极短、变式上从未成功 | 可能检索而非思考 | 换问法验一次 |

> **一个稳定复现的错误，比一次偶然的正确信息量大得多。** 前者暴露了完整的错误推理路径，
> 后者可能什么都没暴露。

**这是全清单里最便宜的一项**：输入是 `(题目, 孩子原话, 正确答案)` 三元组，三样都已在库里。
不是「加埋点」，是「去读已存的东西」。

## 5.4 教 AI（一次交互测三件事）

孩子教 AI，AI 装不懂只追问，然后用**孩子讲的内容**去做一道新题。

| 检验项 | 怎么判定 | 对应 |
| --- | --- | --- |
| 压缩 | 孩子把多例总结成一条规则 | 变换之一 |
| 迁移 | AI 用这条规则做新题 | L3 |
| 表述完整性 | AI 追问轮数、指出的缺口数 | 新增维度 |

### 致命问题：AI 本来就会

孩子教「比喻」，AI 去做比喻题做对了——**不能说明孩子教得好**。

**差分判定**（必须实现，否则整个机制不可信）：

> **同一个 AI，同一道题，跑两次：一次带孩子的解释，一次不带。**
> **两次答案一样 → 解释没起作用 → 不记通过。**

| 情况 | 含义 |
| --- | --- |
| 无解释答对，有解释也答对 | 泄漏 → 本次不计 |
| 无解释答错，有解释答对 | **解释真的管用 → 最强证据** |
| 两次都答错 | 讲得不够（或题目超纲） |

### AI 追问的边界（否则它又在替孩子思考）

> **AI 的追问不得包含答案里的关键概念词。**

| 允许 | 例子 | 作用 |
| --- | --- | --- |
| 澄清指代 | 「你说的『这个』指哪一个？」 | 逼表述精确 |
| 追问适用边界 | 「那如果是……还算吗？」 | 逼孩子说出反事实条件 |
| 指出缺口 | 「你还没告诉我，什么时候不算。」 | 指缺口但不填缺口 |

**指出缺口是允许的，填上缺口是禁止的。** 这条界线就是「引发者」与「讲解者」的分界。

### 适用边界

只用于**已想通的规律收尾**（没想通就教，教的是背下来的话）；不用于识记型；3 年级以上；
题目必须系统可判。成本最高（每轮 2 次 AI 调用 × 多轮），应**低频高价值**。

### 架构缺口（诚实标注）

`UnifiedContext` **无对话历史字段**；`TurnEngine` 的 `history` 只装工具调用；
协议是「一个提问 → 最多 8 步工具 → 一个 final_answer」，**单轮闭合**。

「教 AI」是**多轮对话**，需要**跨 turn 的会话层**。这是 agent 运行时的结构性改动，
不应为一个功能仓促引入。

## 5.5 迁移缺口（可推，零新表）

`KnowledgePointPool` 的 `extra`（JSON，含 `example` 原文句子）与 `content`（独立表述）可对**同一知识点**测两次：

| 呈现方式 | 测什么 |
| --- | --- |
| 带 `example` 原文语境 | 语境匹配 |
| **脱离原文，换个情境** | 迁移 |

> **注（v4.1 更正）**：本节原文写作 `KnowledgePoint.original_sentence`，与实际不符——
> `KnowledgePoint` 只有 `content` 一个正文字段，全库无 `original_sentence`。
> 真正带原文的是 `KnowledgePointPool.extra` 里的 `example`。

**两者正确率差 = 迁移缺口。** `AnswerRecord.source_type` / `source_id` 已足够关联两次呈现。

### 更好的掌握度定义

`compute_mastery` 返回 0..1，本质是「最近几次对得多不多」——**是近期正确率，不是掌握度**。

> **掌握的深度 = 能承受多远的情境变化。**

| 表现 | 含义 |
| --- | --- |
| 只会在原题上做对 | 绑在原题上 |
| 换数字能做对 | 绑在数字上 |
| 换故事背景能做对 | 规律已抽出 |
| 能举出教材里没有的例子 | 真正拥有这条规律 |

这个阶梯有序、可测，且直接对应三种变换——换数字是「反事实」的最小形式，举新例是「生成」。

## 5.6 元认知：先自评再做

孩子最缺的不是能力，是**校准**。他「以为会了」时最危险，因为那时不会去学。

> **越是不懂的人，越没能力察觉自己不懂。** 所以校准缺口**最大的地方，正是最需要学的地方**。

**推论：不能依赖孩子主动说「我不会」——最需要帮助的人最不会说。**
系统必须从**行为**推断（卡住、乱试、秒过），不能靠询问分流。

### 两种校准失败，处理相反

| 状态 | 表现 | 需要的处理 | 现在能识别吗 |
| --- | --- | --- | --- |
| **过度自信** | 快答、错、不自知 | 变式/陷阱打破 | 不能 |
| **过度谨慎** | 会，但慢、反复改、不敢提交 | 错误安全 + 明确确认 | 不能 |

第二种尤其隐蔽：**过度谨慎的孩子会被误判成不会**，然后系统给他更多同类题，
把谨慎当成能力不足来「治」。这是加量策略最隐蔽的伤害。

### 零成本采集

`AnswerRecord.duration_ms` 存在但没人读。它已能区分：

- 1 秒答对 → 已自动化（原料层达标）
- 40 秒答对 → 还在推导（思考层，尚未自动化）

**这两件事现在被记成同一个 `is_correct=True`。**

# 第五部分附：界面上长什么样（落地形态）

> 本节回答「这些判据变成什么界面」。结论先行：**七项里只有一项需要新页面**，
> 其余是「加一步」「改文案」或纯后台。

## 附.1 答 + 指

`knowledge_page.dart` 现状是一个输入框、提交、显示对错。加「指」之后，提交后**多一步**：

```
1.「他长得像他爸爸」是比喻吗？
   [ 不是              ]  ← 原输入框
        [ 提交 ]
   ↓ 提交后
   👆 你是从课文哪一句看出来的？点亮那一句
   ① 他长得像他爸爸。      ← 点这个（错）
   ② 月亮像一条小船。      ← 点这个（对）
   ③ 云朵仿佛棉花糖。
```

**复用点**：`Annotation` 已有 `quote` / `rects`，阅读器的划句能力已存在——
「指」不是新控件，是**把划句从阅读器搬到答题页**。

四种结果的文案（**第三行最要紧，不能用红叉**）：

| 答案 | 出处 | 反馈文案 |
| --- | --- | --- |
| ✅ | ✅ | 「对了，你找的这句正是关键」 |
| ✅ | ❌ | 「答案对了，但你说的这句不是依据。再看看？」 |
| ❌ | ✅ | 「你找的位置是对的，只是话没说明白。你想说的是……」 |
| ❌ | ❌ | 「我们回去再看看这一句」+ 高亮正确句 |

## 附.2 反向证据题

**无新控件，只改题目内容**——形式上仍是选择题：

```
「他长得像他爸爸。」
这句话在全文里起什么作用？
  ○ 举例说明    ○ 对比两样东西    ○ 只是说他们长得像 ← 正确
```

低年级简化为「这句话在讲谁？」

## 附.3 错误诊断

**完全没有界面**。孩子看到的界面不变，变的是三处后台：

| 变化 | 位置 |
| --- | --- |
| 判分不再只返回 `bool` | `mastery.grade_answer` |
| 错题本改为**追加**而非覆盖 | `Mistake` 加历史 |
| 出题按错误形态选反例 | `task_gen.py` |

**唯一可感知的变化在出题**：不再「同一错出 3 道同类题」，而是出 1 道**打在边界上**的反例。

## 附.4 教 AI（唯一需要新页面）

```
← 现在换你当老师
AI 学生：我不懂什么是比喻，你能教我吗？
  [ 比喻就是把一个东西比作另一个东西 ]  ← 孩子输入
AI 学生：你说的「另一个东西」，是随便什么都行吗？   ← 追问不含答案词
  ↓ AI 去做题
「湖水像一面镜子」是比喻吗？  AI 答：是
✅ 你教明白了！
```

两种失败的处理（**都不能让孩子觉得白讲了**）：

| 情况 | 显示 |
| --- | --- |
| 不带解释 AI 也答对（泄漏） | **静默结束**，记「本次不计」 |
| 追问超 5 轮仍做不出 | 「好像还有点没说清，要不要回去再看看这一课？」 |

## 附.5 迁移缺口

**没有独立界面**——它是同一知识点出两次题，孩子眼里就是两道普通题：

| 第一次（带原文） | 第二次（脱离原文） |
| --- | --- |
| 「月亮像一条小船」用了什么修辞？ | 小明说「他的脸红得像苹果」。这句用的方法和下面哪句一样？ |

唯一可见处在家长端：

```
「像」这条规则
  在课文里能答对 ✅
  换个情境就答不出 ❌
  → 还绑在原文上，不是真的会
```

## 附.6 元认知

**先自评**（在题目前面加一步）：

```
下一题是「比喻和同类比较的区别」
你觉得这题你会做吗？
  [ 肯定会对 ]  [ 可能对 ]  [ 不太会 ]
```

自评与实际的组合即校准数据：说会对但错了 = 过度自信；说不太会但对了 = 过度谨慎。

**「先放一放」按钮**（答题页角落），措辞决定使用率：

| 文案 | 使用率 |
| --- | --- |
| 「我不会」 | 极低 |
| 「先放一放」 | 中 |
| **「这个我还想再想想」** | **最高** |

## 附.7 `duration_ms`

**无界面**，只改反馈文案：

| 情况 | 现在 | 改后 |
| --- | --- | --- |
| 1 秒答对 | 「答对了！」 | 「答得真快，已经不用想了」 |
| 40 秒答对 | 「答对了！」 | 「想了一会儿才想出来，这才是真的会」 |

第二句在**奖励「慢而正确」**，而现在的界面只奖励「快」。

## 附.8 工作量汇总

| 判据 | 界面变化 | 工作量 |
| --- | --- | --- |
| 答 + 指 | 提交后多一步「点亮那句」 | S |
| 反向题 | 无新控件，只改题目内容 | S |
| 错误诊断 | **无界面**，只有出题变化 | M |
| 教 AI | **新页面**（对话式） | L |
| 迁移缺口 | **无界面**，同点出两次 | M |
| 元认知 | 加自评一步 + 一个按钮 | S |
| `duration_ms` | **无界面**，只改文案 | S |

# 第六部分：「不会」的空间（v3 全新，改调度模型）

## 6.1 系统里根本没有「不会」这个状态

| 证据 | 内容 |
| --- | --- |
| `WordMastery.is_weak` | 错过一次就 `True`，直到掌握度 0.9 才转回 `False`——**二元，无第三态** |
| `Task.submit_status` | `not_started \| submitted \| approved`——**没有「先放下」** |
| `Mistake` | `REMOVE_AFTER = 3`，只有「答对 3 次移出」，**没有「暂时移出」** |
| `_gen_dictation` 注释 | 「所有词永不移出（B2）」——**无出口** |

## 6.2 「不会」有五种，系统当成一种

| 类型 | 含义 | 正确响应 | 现在会怎样 |
| --- | --- | --- | --- |
| **没学过** | 还没接触 | 教它 | 混在错词里 |
| **学了没懂** | 需重建理解 | 换表征/给反例 | 加同类题 |
| **懂了没记住** | 提取不自动 | 间隔复习 | 加同类题 ✓（对的） |
| **发展性未到** | 认知能力还没到 | **等，并降优先级** | **反复轰炸** ❌ |
| **不必会** | 超纲/不需要 | 移出，不再出现 | 永远占用名额 ❌ |

第三行是唯一「多练就能好」的，而系统对全部五行用同一个动作。

### 「发展性未到」被当成「薄弱」是最伤人的

| 内容 | 低年级表现 | 后来 |
| --- | --- | --- |
| 分数 | 「为什么 1/2 比 1/3 大」想不通 | 有除法经验后自然通 |
| 负数 | 减法不够减时无法接受 | 数轴表征建立后自然通 |
| 周长与面积 | 认为周长大气面积大 | 操作经验积累后自然通 |

这些不是教不会，是**还不到**。系统判为薄弱 → 反复出题 → 反复错 → `is_weak` 永远 True → 继续出。
**孩子得到的信息是「这一块我天生不行」。**

## 6.3 注意力是有限预算：不放弃等于摊薄

`_gen_dictation` 错词档排序是 `-mistake_count`——**错得越多越优先**。
一个永远学不会的词会长期占据 `due_n` 名额（默认 7 个里的 4 个）。

> **一个词永远学不会 → 永久占用名额 → 挤掉本可以学会的新词。**

错词池只增不减，每天只有 7 个名额。学期过半，孩子可能每天做的都是那几个顽固错词，新课永远进不来。

**不允许「不会」的真实代价，不是多练了几个词，是挤掉了本该学的东西。**

## 6.4 允许不会，才能看见不会

若规则是「每个点都必须通过」，孩子的最优策略是**假装通过**：蒙对、抄、背结论、
直接退出（系统看不见他卡住过）。

> **只有当「不会」是可以合法停留的状态，孩子才会如实暴露「我不会」。**

## 6.5 三条约束（缺一条就退化成放任）

| 约束 | 内容 | 为什么必须有 |
| --- | --- | --- |
| **有复核时机** | 悬置不是删除，到期必须重新出现 | 否则等于放弃 |
| **有数量上限** | 同时悬置的点不超过 N 个 | 否则悬置变成逃避的垃圾桶 |
| **有理由** | 必须标明是哪种（没懂/没到/不必会） | 否则无法决定复核方式 |

| 悬置原因 | 复核时机 | 复核方式 |
| --- | --- | --- |
| 学了没懂 | 3–7 天后 | **换表征**，不是重讲 |
| 发展性未到 | **1–3 个月后**（远长于 SRS 最长 60 天） | 同样内容，看是否自然通了 |
| 不必会 | 不复核 | 从池中移除 |

## 6.6 「知道自己不会」是能力

元认知的另一半：**能准确说出「我不会这个」，并且容忍这个状态**，是会学习的人的核心特征。

不会学习的人只有两种状态：「会」和「我笨」。中间那个「我暂时不会，但我知道它在哪」——是稀缺的。
系统强制二元的 `is_weak`，恰恰**抹掉了这个中间状态**。

零成本采集：让孩子自己标记「这个我还不会」（行为，不是表态）。

| 孩子点了 | 系统得到什么 |
| --- | --- |
| 「这个我还不会」 | 真实自评信号（比「你有把握吗」可靠） |
| 与系统判定比对 | **校准数据**：说不会实际会 → 低估；说会实际错 → 高估 |

# 第七部分：练习排列（v3 新增）

## 7.1 `scheduler.py` 只做了间隔，没做交错

`select_words` 按「到期 > 错得多」排序；`_gen_knowledge` 的 `points` 来自当前这一课。
结果：**同一课、同一属性的题排在一起**——教科书式块状练习。

## 7.2 块状练习为什么让人误以为掌握了

连续做同类题时，**表征一直保持加载，不用切换**。孩子体验到「越做越顺」——
这个顺畅感来自表征没被卸载，不是来自掌握。

真实使用中最难的一步恰恰是：**判断这道题该用哪条规则**。块状练习从不训练这一步。

> **块状练「执行」，交错练「选择」。而现实只考选择。**

## 7.3 交错冲撞从属原理，解法是分阶段

交错会让错误率上升、体验变差。解法不是折中，是**分阶段**（接 2.1 的动态规则）：

| 阶段 | 排列方式 | 目的 |
| --- | --- | --- |
| **新学**（表征未建立） | **块状**：同一规律连做几题 | 建立表征 |
| **巩固**（已想通） | **交错**：与其他规律混排 | 训练「选择」 |

**想通了没，决定能不能上交错。**

## 7.4 顺带修正 SRS 的意义

`INTERVALS = [1,2,4,7,15,30,60]` 只做间隔，没做交错。间隔的真正价值不在「抗遗忘」：

> **间隔的价值在于强迫重新生成路径**——每次复习都从零走一遍，而不是重读一遍。

前提是复习形式要求**重演**，不是重认。若复习只是「再看一遍」，间隔再长也只是维持「认得出」。

## 7.5 遗忘的功能性

遗忘不是失败，是**抽象化机制**：忘掉细节、留下模式——这正是「压缩」本身。

# 第八部分：节奏与注意力（v3 新增）

## 8.1 节奏不是速度，是「等待发生在哪里」

| 位置 | 现状 | 学习上的作用 |
| --- | --- | --- |
| **答案之前** | 无等待，直接给 | 「他自己第一次尝试」——信息量最大的一刻 |
| **卡住之中** | 无（卡不住） | 发现关系的通路 |
| **答案之后** | 无（继续问下一个） | 用自己的话重建一次 |

三处全空。而唯一存在的等待——LLM 响应延迟——**位置恰好是错的**：它等的是机器，不是孩子。

### 答案之前：先试后教

> **在被告诉答案之前先尝试一次，即使尝试是错的，学习效果也显著更好。**

尝试会**激活相关经验**，让后面的正确答案有东西可挂。现在的交互反过来：孩子提问 → AI 回答，
**孩子的第一次产出被系统性跳过**。

### 流式输出在训练被动

SSE 逐 token 推流，表面「体验好」，实际：

| 表面 | 实际 |
| --- | --- |
| 感觉 AI 在思考 | **理解没有在任何地方发生** |
| 感觉很快 | 阅读速度由模型决定 |
| 感觉流畅 | 孩子唯一的动作是「看」 |

**流式把「等待」从体验里删掉了，而等待原本是孩子唯一可能插入自己思考的缝隙。**

| 阶段 | 是否流式 | 理由 |
| --- | --- | --- |
| 工具调用 / 检索 | **保留**（`正在查生词释义…`） | 解释等待，不泄漏答案 |
| 最终答案 | **考虑改为一次性给出** | 逐字推流训练被动 |

### 指标冲突（无法回避）

| 指标 | 越快越好 | 学习效果 | 关系 |
| --- | --- | --- | --- |
| 首字延迟 | ✅ | ❌ | **直接对立** |
| 对话轮次 | ✅ | ❌ | **直接对立** |
| 单次会话时长 | ✅ | 5–8 分钟后递减 | 倒 U |
| 错误率 | ❌ | **需要一定的错误** | 对立 |

**慢就是体验差，而体验差是真实的。** 唯一能做的是**把慢换成有理由的慢**：

| 无理由的慢 | 有理由的慢 |
| --- | --- |
| 转圈 3 秒 | 「先说说你怎么想的」 |
| 假装在思考 | 「我查到两种解释，你想先看哪个」 |

**节奏设计的本质是把延迟转化成动作要求，而不是加延时。**

### 假等待的判据

> **真等待要求孩子做一个动作；假等待只是让时间流逝。**

`sleep(2)` 是剧场：孩子立刻感知「卡了」，体验变差，学习也没变好。
所以「节奏」在实现上不是延时参数，是**交互关卡**。

### 反馈时机按类型分

| 内容类型 | 立即反馈 | 延迟反馈 |
| --- | --- | --- |
| 程序性（怎么算、怎么写） | **更好** | 差 |
| 概念性（为什么、什么时候不成立） | 差 | **更好**（迫使自己复审） |

| 类型 | 反馈时机 |
| --- | --- |
| **原料层**（听写、默写） | **立即** |
| **思考层**（规律、原理） | **延迟一句**——先让孩子说「为什么」 |

### 会话的结束点

> **在孩子还想做的时候停，而不是做不动的时候停。**

结束在精疲力尽处，孩子对「学习」的记忆就是疲惫；结束在还剩一点的地方，下次启动成本更低。

信号（已在数据里）：开始变慢、错误变多、反复回看。不是看时钟，是看**行为**。

## 8.2 注意力：问题塑造知觉

### 注意力分三层，且有预算关系

| 层 | 看什么 | 消耗 |
| --- | --- | --- |
| **解码层** | 这个字怎么念、这句什么意思 | 认字不熟就吃满 |
| **内容层** | 发生了什么、谁做了什么 | 中等 |
| **结构层** | 为什么这样安排、作者在干什么 | 剩余的全部 |

三层不是并列选项，是**同一份工作记忆的竞争关系**。生字多的孩子解码层吃满，
「只看到表面」不是不想深入，是**没预算了**。

> **对识字量不足的孩子，「引导他看结构」是无效的——不是方法不对，是他没有可用的算力。**

### 核心机制：问题塑造知觉，不是反过来

「你要看结构」对孩子没用，因为他不知道结构长什么样。但每次被问「作者为什么先写这个」，
**做够几次后，安排本身就会变得可见**。

> **不是先有注意力再有好问题，而是好问题逼出注意力。**

所以「教阅读策略」是陷阱：教「找中心句」，孩子会把策略当成又一条要背的规则——**又回到加量**。
**不要做「阅读方法」课程，要改题目本身。**

### 现有题目在训练什么

`question_gen.py` 对「问什么层面」**没有任何约束**，兜底题是「文中作者表达了什么感情？」
——**最难验证、最容易蒙、最不需要看具体位置**的一类题。

现在的题在训练：**扫全文、抓整体印象、记住常见情感词**。

### 标注数据已经存在

`Annotation` 存了 `kind`（highlight/underline/note/glossary）、`quote`（选中原文）、`page_number`。
**孩子划了哪句、划几次、划多长——注意力位置快照，全在库里，但没人读。**

| 指标 | 算法 | 含义 |
| --- | --- | --- |
| **标注密度** | 标注总长 / 课文总长 | 越高越「全都要」，注意力未分化 |
| **标注粒度** | `quote` 长度分布 | 偏短=解码层，偏长=内容层 |
| **标注类型** | `kind` 分布 | 有 `note` 说明在做加工 |

**划得越多，说明越没看出哪里重要**——选择性的本质是排除，划满一篇等于没做排除。

这是全系统**唯一完全免费的注意力测量**，但只对愿意标注的孩子有效，只能做辅助信号。

### 真实仪器采不到

眼动（停留、回看、跳读）采不到，只能靠代理指标。代理强度：

| 代理 | 强度 |
| --- | --- |
| 答 + 指的一致性 | **强**（行为证据，非推断） |
| 标注位置与粒度 | 中（只覆盖会标注的孩子） |
| 每题耗时 `duration_ms` | 弱（有但没人读） |

# 第九部分：从属原理（v3 扩充）

| 优先级 | 条件 | 含义 | 可观测指标 |
| --- | --- | --- | --- |
| 1 | **低门槛开始** | 单次任务落在一次注意力之内（5–8 分钟） | 开始率、放弃点位置 |
| 2 | **难度适配** | 略高于当前能力，由**数据**决定而非年级 | 连对/连错分布、难度切换 |
| 3 | **错误安全** | 错误不产生惩罚性反馈，家长端不得把掌握度变成考核指标 | 连错后重试率、催办与代做痕迹 |
| **4（v3 新）** | **允许不会** | 有些内容当前不该出现（不是难度问题） | 悬置数量、复核时机命中率 |

## 9.1 错误安全是数据质量的前提（结构性冲突）

> **如果家长端把错题数当成考核，孩子就会隐藏错误；错误被隐藏，诊断体系整个失效。**
> **「错误安全」不是道德要求，是数据质量的前提。**

用户选择**软约束**（不限制家长端具体展示）。代价必须诚实标注：
**诊断能力的天花板由家长端决定，而软约束意味着这个天花板不受控。**

软约束要能工作，必须给家长端**换掉他们看的数字**——不是加约束，是**换指标**：

| 现在给家长的（结果） | 应该给家长的（环境/状态） |
| --- | --- |
| 错题 12 个 | 「像」这个规则他还在用旧的理解，已安排反例 |
| 掌握度 62% | 本周有 4 天孩子自己开始了 |
| 薄弱：听写 | 孩子卡住时你追问了 3 次 |

第一行最有价值：**告诉家长「孩子正在纠正什么」，而不是「孩子错了多少」**。
前者让家长看到进展，后者只让家长看到缺口。同样是坏消息，一个指向补课，一个指向过程。

# 第十部分：分层裁判（内容 × 年龄）

## 10.1 内容维度

| 类型 | 适用内容 | 达标要求 | 通过判据 |
| --- | --- | --- | --- |
| **探究型** | 数学规律、句型、修辞、周长面积 | 三种变换至少一种 + 过反检索 | 引导链归纳（压缩）+ 归类（反例）+ 陷阱（反事实） |
| **识记型** | 生字、单词、古诗、短语 | **不要求变换**，要求检索自动化 | 无提示产出、隔期仍能取（认→背→测） |
| **习惯/情感型** | 按时开始、不畏难、敢提问 | 不受原理本体裁定 | 只受从属原理裁定 |

## 10.2 年龄维度（与内容维度交叉）

| | 低年级（1–2） | 中年级（3–4） | 高年级（5–6） |
| --- | --- | --- | --- |
| **冲突形式** | 先猜再看结果 | 反例打破规则 | 自己构造反例 |
| **产出通道** | 动作/图形为主，语言为辅 | 语言 + 图形 | 以语言为主 |
| **工作记忆** | 元素必须外化 | 部分外化 | 可内部操作 |
| **教 AI** | 不适用 | 可用 | 可用 |
| **反向证据题** | 简化为「这句在讲谁」 | 可用 | 可用 |

## 10.3 现有功能裁定（v3 更新）

| 功能 | 裁定 | 层级 | 理由 |
| --- | --- | --- | --- |
| 递进引导链 `guide` | **达标** | 思考层 | 压缩 + 反事实 + 生成，三层痕迹齐全，是样板 |
| 陷阱题 `trap` | **达标（中高年级）** | 思考层 | 反事实。**缺预测步**，冲突强度靠运气；**不适用低年级** |
| 识记「认→背→测」 | **达标** | 原料层 | 检索自动化，不得宣称理解 |
| 听写 | **达标** | 原料层 | 同上；须标注「记住了，不等于会用」 |
| 归类 `classify` | 部分 | 思考层（弱） | 有辨认无压缩，不要求说出共同点 |
| 阅读理解题 | 部分 | 混合 | 无层面约束、无反事实验证、**不要求指出处**、训练整体印象而非结构 |
| 边读边问 `/api/ask` | **部分（偏低）** | 思考层 | 主体是 AI（孩子未先产出）、无 L1 证据、**无等待（节奏缺失）**、流式训练被动 |
| 思维训练小游戏 | 不受裁定 | 动机 | 习惯/情感型，不产生学科掌握。**唯一在计时的地方** |
| 积分 | 不受裁定 | 动机 | **不得用于判定掌握度** |
| `weakness_report` | **不达标** | — | 只统计题型计数，是计数不是诊断 |
| `is_weak` 二元状态 | **不达标** | — | 无第三态，把「还没到」误判成「薄弱」 |
| `AnswerRecord` | **未使用** | — | 存了 `student_answer`/`duration_ms` 但全链路不读 |

# 第十一部分：裁决程序

## 11.1 新功能开工前必答 9 问

| # | 问题 | 不通过的表现 |
| --- | --- | --- |
| 1 | 属于哪一类（探究 / 识记 / 习惯）？ | 「都涉及」＝没定类，退回 |
| 2 | 训练的**哪个关系**？能用一句话说出吗？ | 「练习阅读能力」＝无关系 |
| 3 | 孩子要做哪种变换（压缩 / 反事实 / 生成）？ | 原料层须明写「无变换，不得宣称理解」 |
| 4 | 通过证据在**无提示**下怎么取到？能否被「照搬输入」解释？ | 能 = 不算通过 |
| 5 | 这个变换**由谁先完成**，孩子还是 AI？ | 「AI 归纳、孩子点头」＝演示 |
| 6 | **产出通道**是什么？语言是不是唯一通道？ | 只用语言 → 会冤枉低龄孩子 |
| 7 | **适用年龄**是多少？冲突形式匹配吗？ | 低年级上反事实题 = 测抑制控制 |
| **8** | **测不准时怎么办？能不能记「未决」而非强行判？悬置如何回归、何时到期？** | 「多给点分」= 错解法；正确动作是**到期改内容** |
| 9 | 它影响「愿意学」还是「学会了没」？**不得混** | 「答对有积分，所以掌握了」 |

## 11.2 七条硬约束

1. **成功指标必须落在已有数据表上**（`WordMastery` / `KnowledgeMastery` / `AnswerRecord` /
   `BrainGameResult` / `Annotation` / `Mistake` 等）。落不上去说明测不出东西，先别做。
2. **不得交叉套用标准**（探究型标准不要求识记型；识记型标准不放过探究型；原料层达标不宣称理解）。
3. **不得用积分 / 时长代表掌握度。**
4. **不得用「加同类题」应对关系缺口。**
5. **不自动化学没想通的东西**（判断顺序必须是「想通 → 再自动」）。
6. **不得省略年龄维度**；低年级不得用反事实作为主要冲突形式。
7. **不得把「未决」当免责话术**：每个未决必须到期、必须归属到内容/教学/时间之一，否则算系统失职。
