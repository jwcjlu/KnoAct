# 语文听写课堂式报读（组词 / 短释义）设计

日期：2026-11-28  
状态：已确认（brainstorming），待实现  
范围：语文 `task_type=dictation` 的 TTS 报读文本生成与下发；任务生成时查缺补组词/短释义；单字宽判；家长端「报读待补」提示。英语听写不改。

## 背景与问题

现状（`student-app` 听写）：`speak(word.word)`，只读目标字/词本身。语文存在大量同音字；课堂听写惯例是「读音 + 组词」或「词语 + 短释义」，单靠字音既不像老师报听写，也容易让孩子写错同音字。

现有「看提示」（拼音 → 释义）是**主动点按**的视觉自救，不能替代报读口令本身。

本改动属于**识记型 / 原料层**：目标仍是听 → 写出正确字形；报读增强是消歧与课堂节奏，**不得**据此宣称「会用 / 理解」。

## 目标（已确认）

1. 语文听写报读贴近课堂：**全部**听写条目（不限同音字）。
2. 单字：`「{字}，{组词}的{字}」`；词语：`「{词}，{短释义}」`。
3. 在**生成听写任务时**查缺；缺则 AI 补全并写回词库可复用；听写当场只读固化文本。
4. 补全失败：任务仍生成，兜底读两遍，标记待补，家长可见。
5. 单字批改：写出目标字 **或** 组词整词都算对（宽判）。

## 已锁定决策

| 项 | 决定 |
|----|------|
| 动机 | 贴近课堂报听写（不止同音消歧） |
| 范围 | 语文全部听写项；英语不变 |
| 补全时机 | `_gen_dictation` 选出词之后、写 `Task.content` 之前 |
| 补全失败 | 任务照出 + `speak_incomplete`；家长可见待补 |
| 句式 | 单字「字 + 组词」；词语「词 + 短释义」 |
| 单字/词语判定 | `kind` 优先；含糊时按汉字数 1 / ≥2 |
| 批改 | 单字接受 `[字, 组词]`；词语只接受目标词 |
| 不做 | 听写当场实时 AI；拆课全量预补；家长编辑组词 UI；报读完整度进掌握度/积分 |

`kind` 映射（与 `word_kinds` / 听写种类配置对齐）：

- `write` / `recognize` → 单字报法  
- `phrase` / `word` → 词语报法  
- 其它 / 空 → 按目标串汉字数兜底  

## 方案选择

采用「任务生成时补全 + 固化报读文本」（方案 2），而非前端临时拼装或拆课全量预补。

## 第一部分：数据

### 词库可复用线索（不破坏现有 `extra`）

`WordBank.extra` 仍为明文「拼音 + 释义」，供「看提示」解析。新增结构化存放（实现任选其一，推荐独立 JSON 列以免污染 `extra`）：

| 字段 | 含义 |
|------|------|
| `compound` | 单字组词（须包含该字），如「事情」 |
| `gloss_short` | 听写用短释义（约 4–8 字）；词语报法优先用此，否则尝试从 `extra` 截短 |

可选元数据：`cue_source`（`extract` / `ai` / `manual`）、`cue_updated_at`。

### 任务 content 固化

`_gen_dictation` 写入的每条（在现有 `id/word/extra/kind` 上扩展）：

```json
{
  "id": 1,
  "word": "事",
  "extra": "shì 事情",
  "kind": "write",
  "speak_text": "事，事情的事",
  "speak_incomplete": false,
  "accept": ["事", "事情"]
}
```

| 字段 | 含义 |
|------|------|
| `speak_text` | TTS 整句；客户端优先读此字段 |
| `speak_incomplete` | `true` = 本次用了兜底报读 |
| `accept` | 批改可接受写法列表 |

旧任务无上述字段：客户端回退 `speak(word)`；批改回退只接受 `word`。

## 第二部分：任务生成时查缺补全

挂点：`backend/app/services/task_gen.py` 的 `_gen_dictation`，**仅 `subject == "语文"`**。

```
选出 picked
  → 对每条判定报法类型（kind → 字数兜底）
  → 查缺：单字缺合格 compound；词语缺可用短释义
  → 待补列表批量 AI（json_mode，整批一次优先）
  → 成功写回 WordBank 可复用字段
  → 拼 speak_text / accept / speak_incomplete
  → 写入 Task.content
```

### 查缺规则

- 单字：已有 `compound`，且目标字 ∈ compound、汉字长度 **2–4** → 不缺。  
- 词语：已有 `gloss_short`（汉字长度 **≤8**），或能从 `extra` 去掉拼音段后得到 ≤8 字的释义 → 不缺。  
- **种子化（免 AI）**：单字若尚无 `compound`，但 `extra` 释义段本身是含该字、长 2–4 的词（如 `extra="shì 事情"` →「事情」），可直接写入 `compound`，不算 incomplete。  
- 否则入待补。

### AI 补全约束

- 单字：组词含该字、汉字长 2–4、小学常用、避免生僻整词。  
- 词语：短释义汉字长 4–8（上限 8），不写成长讲解。  
- 超时/未配置/解析失败：**不阻断**任务；该条兜底。  
- 已有合格线索不重复调用。  
- 整批设短超时；超时则剩余全部兜底。

### 拼装

| 情况 | `speak_text` | `speak_incomplete` | `accept` |
|------|--------------|--------------------|----------|
| 单字齐全 | `{字}，{组词}的{字}` | false | `[字, 组词]` |
| 词语齐全 | `{词}，{短释义}` | false | `[词]` |
| 兜底 | `{目标}，{目标}` | true | `[目标]`（单字若无组词则仅目标字） |

## 第三部分：播报、批改与提示

### 播报（Flutter 学生端）

- 纸质流 / 屏幕书写：`speak(speak_text ?? word)`。  
- 「重听」同一句；不在重听时触发 AI。  
- 英语路径不变。

### 批改

- 掌握度 / 错题本仍挂 `WordBank.id` 与目标 `word`。  
- 单字：`written` ∈ `accept`（目标字或组词）→ 对。  
- 词语：仅目标词。  
- **主路径**：手写视觉批改（`/api/dictation/grade-handwriting`）。请求里每项在 `word` 外增加 `accept`（或服务端按 task content 合并）；`grade_handwriting` prompt 改为「识别写法命中 `accept` 任一即对」。  
- 若仍存在屏幕书写/旧打字判分入口，同样读 `accept`；**不为此单独扩 scope 重做闲置 API**。  
- 宽判只影响当次对错，不宣称「会用该组词」。

### 与「看提示」分工

- 语音 = 课堂报读。  
- 提示仍为：生字拼音 → 释义；不把组词塞进提示第一级。  
- `speak_incomplete` 不弹窗打断；孩子仍可点提示。

### 积分 / 掌握度

报读是否完整**不**影响积分、完成态或掌握度计算。

## 第四部分：家长「报读待补」

- 今日任务列表：语文听写若存在 `speak_incomplete=true`，显示「报读待补 N」。  
- 展开列出待补目标字/词；不展示底层错误栈。  
- 补救：沿用已有「重新生成今日任务」（force generate）；首期不做家长手改组词。  
- API：任务列表可附带 `speak_incomplete_count`（或前端数 content），减少家长端盲目解析。  
- 该标记是决策提示，不进掌握度百分比。

## 错误处理

| 场景 | 行为 |
|------|------|
| AI 未配置 / 失败 / 超时 | 任务生成成功；相关条兜底 + `speak_incomplete` |
| 组词不含目标字 | 视为无效，不写库，该条 incomplete |
| 旧客户端 / 旧任务 | 回退读 `word`、只接受 `word` |
| 非语文 | 不走本逻辑 |

## 测试要点

- 单字有 compound → 句式与 `speak_incomplete=false`  
- 词语有短释义 → 「词，释义」  
- AI 失败 → 任务仍在，兜底 + 家长可见待补数  
- 已有线索不重复调 AI  
- 英语听写行为不变  
- 批改：单字「事」或「事情」都对；词语只接受目标词  
- 无 `speak_text` 旧任务 → 客户端回退  
- 「看提示」拼音/释义不被改坏  

## 成功指标（落在已有表）

- 语文听写任务 `content` 中带 `speak_text` 的比例上升；`speak_incomplete` 比例可观测并随补全改善下降。  
- 不引入新的「掌握度因报读扣分」路径。  
- 错题本仍按目标 `word` / `word_bank_id` 归并。

## 与学习第一性原理的对齐（摘要）

| 问 | 答 |
|----|-----|
| 类型 | 识记型（原料层） |
| 变换 | 无；不得宣称理解/会用 |
| 通过证据 | 无提示写出目标字形（宽判允许组词整词，仍是字形产出） |
| 主体 | 孩子写；AI 只在任务生成时补报读材料 |
| 通道 | 听（语音）→ 写（手写/屏幕） |
| 年龄 | 全小学听写适用；课堂报法本身是低龄友好消歧 |
| 测不准 | 报读 incomplete 不判孩子不会，只标内容侧待补 |
| 愿学 vs 学会 | 报读完整度只影响愿学/可听清，不参与学会判定 |
